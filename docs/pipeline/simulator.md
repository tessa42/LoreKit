# Simulator 파이프라인 설계 문서

> 이 문서는 Simulator 기능의 AI 파이프라인 구조와 설계 의도를 기술합니다.
> Claude Code 등 AI 코딩 보조 도구가 파이프라인 수정 시 반드시 참조하세요.

---

## 기능 개요

캐릭터 이름, 분위기, 세계관을 입력하면
그 조합에 어울리는 캐릭터 카드(설정 + 서사 + 대사)를 생성합니다.

바이럴 콘텐츠 감성의 뽑기형 기능으로,
**비로그인 허용** / **씨앗 무료** / **저장 시 로그인 유도** 구조입니다.

---

## 입력 구조

```ts
interface SimulatorInput {
  name: string    // 캐릭터 이름
  mood: string    // 분위기 (10개 중 하나)
  genre: string   // 세계관 (11개 중 하나)
}
```

### 분위기 목록 (10개)
`피폐` `달달` `힐링` `새드` `코믹` `감동` `호러` `블랙코미디` `몽환` `일상`

### 세계관 목록 (11개)
`현대` `현대판타지` `판타지` `SF` `무협` `스팀펑크`
`사이버펑크` `포스트아포칼립스` `호러` `역사` `이세계`

---

## 파이프라인 구조

```
normalize → load-context → generate → format
```

| 단계 | 모델 | 이유 |
|---|---|---|
| normalize | 없음 | 기계적 검증 |
| load-context | 없음 | 가이드 텍스트 조립 |
| generate | Claude Sonnet 4.6 | 고품질 카드 생성 |
| format | 없음 | JSON 파싱 |

---

## 단계별 설계 의도

### 1. normalize.ts
**역할**: 입력값 검증

- name 필수값 확인
- mood가 10개 목록 중 하나인지 확인
- genre가 11개 목록 중 하나인지 확인

---

### 2. load-context.ts
**역할**: 분위기/세계관 가이드 텍스트 조립

`contexts/moods.ts`와 `contexts/genres.ts`에서
선택된 mood/genre에 해당하는 가이드 텍스트를 불러와
system 프롬프트를 조립한다.

**핵심**: 작품명 직접 언급 없이 문서 형식의 특징만 추출하여 주입.
"SCP 스타일로" 같은 지시는 내용까지 딸려오므로 사용하지 않는다.

---

### 3. generate.ts
**역할**: 캐릭터 카드 생성

모델: `claude-sonnet-4-6`
temperature: `1.0` (다양성 확보)
max_tokens: `600` (카드는 짧고 임팩트 있게)

**출력 형식 (JSON)**:
```json
{
  "summary": "직업/역할을 포함한 한 줄 설정 요약 (20자 내외)",
  "story": "2~4문장 스토리텔링. 과거·현재·내면 갈등 포함.",
  "quote": "시그니처 대사 한 줄"
}
```

**다양성 확보 원칙**:
- 흔한 클리셰(평범한 고등학생, 기억상실, 선택받은 자) 피하기
- 매번 다른 직업/능력/과거/관계 조합
- 한국 서브컬처 독자가 "이 설정 좋다"라는 반응이 나와야 함

## 분위기 가이드 원칙

분위기별 가이드는 AI에게 작품명이 아닌 **감성과 구조**로 설명한다.

예시:
- **피폐**: 극한까지 내몰린 인물에게서 눈을 뗄 수 없는 서사. 체념과 미련 사이. 상처는 행동과 말투에서 배어나온다.
- **블랙코미디**: 세상이 개판인 걸 알면서 쿨하게 인정하고 적응해버린 인물. 냉소적이지만 찌질하지 않고, 신랄하지만 유쾌하다.

전체 가이드: `src/lib/ai/pipeline/simulator/contexts/moods.ts` 참조

## 설계 원칙

**바이럴 우선**
입력 허들 최소화. 이름 + 버튼 2개 클릭으로 완성.
같은 조합이어도 매번 다른 결과 → "한 번 더" 욕구 유도.

**비로그인 허용**
진입장벽을 낮추고 저장 시점에 로그인 유도.
sessionStorage에 결과 저장 → 로그인 후 아카이브 저장.

**씨앗 무료**
초기 유입 및 바이럴 확산용 기능.
Lorecraft/Lorecheck에서 씨앗 수익 창출.
